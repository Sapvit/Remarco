  <h1>Remarco</h1>
  <p>
    <strong>Remarco</strong> is a prototype of a hybrid application that combines notes, reminders, and a micro-CRM for local use.
  </p>
  <h2>About the Project</h2>
  <p>
    This application allows you to:
    <ul>
      <li>Create and manage peers (clients, partners, etc.)</li>
      <li>Add related contacts (email, Telegram, etc.)</li>
      <li>Keep a history of meetings and notes for each peer</li>
      <li>Set reminders related to peers and meetings</li>
      <li>Attach files and documents to notes</li>
    </ul>
  </p>
  <p>
    The current version is a visual prototype with a simple local data store (CoreData). This is not a finished product but a concept demo that can be further developed.
  </p>
  <h2>Status</h2>
  <p>
    This project is not finalized — it is a prototype/mockup and is not intended for production use.
  </p>
