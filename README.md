  <h1>📒 Remarco</h1>
  <p>
    <strong>Remarco</strong> is a lightweight prototype of a hybrid personal productivity app – combining ✍️ <em>notes</em>, ⏰ <em>reminders</em>, and 👥 <em>micro-CRM</em> functionality — all designed for local use.
  </p>

  <div class="section">
    <h2>📌 About the Project</h2>
    <p>Remarco lets you:</p>
    <ul>
      <li>👤 Create and manage peers (clients, partners, collaborators)</li>
      <li>🔗 Add related contacts (email, Telegram, etc.)</li>
      <li>📝 Track meetings and store notes per peer</li>
      <li>⏳ Set reminders linked to people or meetings</li>
      <li>📎 Attach files/documents to notes</li>
    </ul>
    <p>
      ⚠️ This is a <strong>concept demo</strong> built on <code>CoreData</code> for local storage. Not intended for production use.
    </p>
  </div>

  <div class="section">
    <h2>🚧 Project Status</h2>
    <p>
      The app is in <strong>prototype/mockup</strong> stage. Visuals and core structure are functional, but development is ongoing.
    </p>
